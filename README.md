🌊 Indian Flood Prediction Analysis | Power BI


📌 Project Overview

Indian Flood Prediction Analysis is an interactive Power BI dashboard developed to analyze historical flood events across India from 2020 to 2026.

The project brings together flood-event, weather, rainfall, river-level, district, state, and date-related information into a single analytical dashboard.

The objective is to understand the frequency, severity, geographical distribution, human impact, and economic impact of floods across India.

The dashboard transforms complex flood-related data into interactive visualizations that make it easier to identify patterns, compare regions, and understand the impact of flood events.

---

🎯 Project Objectives

The main objectives of this project are:

* Analyze flood events across India from 2020–2026.
* Understand the geographical distribution of floods.
* Compare flood events across different states and districts.
* Analyze flood severity.
* Study the number of fatalities caused by floods.
* Analyze the population affected by floods.
* Understand the number of displaced people.
* Analyze the economic damage caused by flood events.
* Study rainfall and river-level conditions.
* Identify yearly flood trends.
* Compare flood severity across regions.
* Present flood-related information through an interactive Power BI dashboard.
